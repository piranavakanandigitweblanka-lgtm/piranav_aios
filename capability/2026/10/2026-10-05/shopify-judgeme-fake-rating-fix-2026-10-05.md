## Purpose
Detect and remove Judge.me sample/demo data that causes fake 4.5-star ratings to appear on live product pages.

## Business Problem Solved
Judge.me app blocks in `templates/product.json` can contain `"review_data": "sample_data"` — a development/preview mode flag. When active on a live store, it forces the widget to display hardcoded fake ratings (4.5 stars / 10 reviews) regardless of actual review data. This is invisible in Shopify Admin and can persist from theme development into production. It damages customer trust when users realise the ratings are not real, and creates structured data integrity issues.

## When To Use
- A Shopify store uses the Judge.me app for product reviews
- Product pages display a star rating but the store has zero or very few real reviews
- The rating count suspiciously matches (e.g. exactly "4.5/10 reviews" on all products)
- A theme was recently developed, cloned, or migrated and reviews seem too uniform

## When NOT To Use
- If the store has real reviews verified in the Judge.me dashboard — ratings are genuine
- If the star rating is generated by a different reviews app (not Judge.me)

## Required Inputs
- Access to `templates/product.json` in the Shopify theme
- Confirmed that Judge.me app blocks are present in that file

## Execution Steps

### Step 1 — Detect the issue
Run the following grep on the template file:
```bash
grep -o '"review_data":"[^"]*"' templates/product.json
```
If any result shows `"review_data":"sample_data"`, the fake rating is active.

### Step 2 — Find all affected Judge.me app block instances
Open `templates/product.json`. Search for all occurrences of `"review_data"`. There may be multiple blocks (active and disabled). Fix ALL instances, not just the active one — disabled blocks can be re-enabled.

### Step 3 — Change `sample_data` to empty string
For each instance:
```json
Before: "review_data": "sample_data"
After:  "review_data": ""
```
Setting `review_data` to `""` instructs Judge.me to use real store review data.

### Step 4 — Verify the JSON-LD (do not modify unless confirmed broken)
Check `sections/main-product.liquid` for any hardcoded `aggregateRating` output in the `<script type="application/ld+json">` block. A correctly implemented JSON-LD block gates on real metafield data:
```liquid
{%- if ld_review_count > 0 -%}
  "aggregateRating": { ... }
{%- endif -%}
```
If gated correctly — do NOT modify it. Only remove a hardcoded `else` block if one exists that outputs fake data.

**Note from this investigation:** `main-product.liquid` was already correctly gated. Only `product.json` required changes.

### Step 5 — Deploy and verify
Push updated theme to Shopify. Check a product page that has zero reviews — confirm no star rating appears. Run Google Rich Results Test on a product URL to confirm no `aggregateRating` in structured data for unreviewed products.

## Known Limits
- This fix applies to Judge.me app blocks in `templates/product.json` only. Other review apps (Okendo, Yotpo, Stamped) use different configuration mechanisms
- Disabled app blocks should also be fixed — they can be re-enabled accidentally
- The JSON-LD structured data block is a separate concern and was NOT the issue in this case — verify independently before modifying

## Reuse Path
Apply to any Shopify store where Judge.me is installed and fake ratings are suspected. The grep command and the `review_data` fix are identical across all Shopify themes using the Judge.me app block integration.
