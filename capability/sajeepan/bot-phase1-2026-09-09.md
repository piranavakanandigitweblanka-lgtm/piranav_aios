# Capability — Sajeepan Bot Phase 1: Deterministic Decision Engine
**Date:** 2026-09-09
**Status:** LOCAL — NOT DEPLOYED
**Phase:** 1 of N

---

## What This Capability Does

Adds a parallel deterministic path to the existing Sajeepan AI Assistant.
The bot generates a prioritised action queue from verified R1/R2/R3/R4 data WITHOUT calling any AI model.

AI remains available for explanation/conversation via the existing /brief and /chat routes.
This is not a replacement — it is an additional path.

## Architecture

```
R1/R2/R3/R4 data  (via existing _gather_data)
        ↓
build_candidate_registry  (existing ai_validator)
        ↓
_get_done_candidate_ids   (existing 7-day exclusion)
        ↓
_dedup_registry           (NEW — conservative root-cause deduplication)
        ↓
build_action_queue        (NEW — deterministic, no AI)
        ↓
GET /api/sajeepan/bot/queue  (NEW endpoint)
```

Parallel existing path (unchanged):
```
build_candidate_registry → validated_brief_call → AI → validate_ai_task → /brief
```

## New Components

### `_root_cause_id(candidate)`
Builds a stable, traceable root-cause identifier:
- Products with campaign_id: `{rule}:{item_id}:{campaign_id}`
- Products without campaign_id: `{rule}:{item_id}`
- Campaigns: `{rule}:{name}`
- Search terms: `{rule}:{term}`

Same product in different campaigns → different root cause IDs (not merged).
Cross-business-rule deduplication NOT performed — same product in feed_level1 AND 0_conversions_spending gets two IDs.

### `_dedup_registry(registry)`
Conservative deduplication on root_cause_id.
When two candidates share the same root_cause_id → higher-cost entry wins.
Returns new dict — does not mutate input registry.

### `_deterministic_action(candidate)`
Generates action/why/impact text from verified registry metrics.
All values come from verified data. UNKNOWN surfaced when value unavailable.
No AI model called.

### `build_action_queue(registry, data, max_tasks=5)`
Sorts deduplicated candidates by priority (high→medium→low) then cost (desc).
Returns up to 5 action items with: candidate_id, root_cause_id, business_rule,
requirement, priority, action, why, impact, authority, period, metrics.

### `GET /api/sajeepan/bot/queue`
Auth-gated (same token as AI routes).
Returns deterministic queue + candidate_count + excluded_count + period.
`"deterministic": true` in response confirms no AI involvement.
