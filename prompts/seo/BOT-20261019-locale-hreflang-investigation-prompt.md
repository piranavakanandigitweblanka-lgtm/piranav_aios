# BOT-20261019 — Shopify Markets Locale URLs in UK Google Search Results

## Task Description

Investigate why Polish (/pl/), Dutch (/nl/) and Spanish (/es/) locale URLs generated by Shopify Markets are appearing in UK Google Search Console (GSC) with UK impressions and clicks. Determine if a technical defect exists in hreflang or canonical implementation, or if this is expected behaviour (international users in the UK).

## Scope

- Store: LEDSone UK (ledsone.co.uk)
- Ticket: BOT-20261019-ORGANIC-EXC-03
- Investigation only — NO production changes, NO theme file edits, NO noindex/redirect/remove of locale URLs
- The 3 markets (Poland / Netherlands / International with Spanish) are required for international customers and must be retained

## What to Build / Investigate

1. Read theme.liquid — confirm `{{ canonical_url }}` is present for self-referencing canonical
2. Read snippets/seo-noindex.liquid — check for active or commented-out hreflang code
3. Read layout/theme.liquid — confirm `{% render 'seo-noindex' %}` is present in `<head>`
4. Confirm whether Shopify Markets auto-generates hreflang tags (check live source HTML if available)
5. Check if hreflang uses language-only codes (`pl`) or language-region codes (`pl-PL`, `nl-NL`) — language-only may cause locale targeting ambiguity
6. Pull UK GSC data for /pl/, /nl/, /es/ URL paths filtered by Country: United Kingdom
7. Assess whether current impressions/clicks are consistent with Polish/Dutch/Spanish-speaking users in the UK (i.e., expected behaviour) vs. a defect causing English pages to be replaced

## Key Technical Context

- Shopify Markets generates hreflang automatically when languages are published — separate from any custom Liquid code
- A custom hreflang loop exists in seo-noindex.liquid but is commented out — was written 2025-10-12 by Piranav
- `{{ canonical_url }}` in theme.liquid produces self-referencing canonicals on all URLs including locale paths
- Locale URL format: `/pl/collections/…`, `/nl/products/…`, `/es/`

## Expected Output

- Confirmed status of: (a) self-canonical on locale URLs, (b) hreflang tags present/absent and code format

- Root cause assessment: defect or expected behaviour
