## Exact Change — Logic (lines 446–477 after edit)

### BEFORE (single condition, product-level only)

```liquid
{% comment %} piranav add stock icon2026/01/22 {% endcomment %}
      <div class="product-stock">
{% if product.available %}
  <span class="in-stock">
    <svg ...check icon...></svg>
    In Stock
  </span>
{% else %}
  <span class="out-of-stock">Out of Stock</span>
{% endif %}
</div>
{% comment %} end stock {% endcomment %}
```

**Why it was wrong:** `product.available` is `true` when at least one variant is available. A product with 1 of 6 colours available shows "In Stock".

### AFTER (three-state, variant-aware)

```liquid
{% comment %} piranav add stock icon2026/01/22 — partial-stock fix 2026-10-07 {% endcomment %}
<div class="product-stock">
  {%- if variant != nil -%}
    {# Variant card — show availability of this specific variant #}
    {%- if variant.available -%}
      <span class="in-stock">...In Stock...</span>
    {%- else -%}
      <span class="out-of-stock">Out of Stock</span>
    {%- endif -%}
  {%- else -%}
    {# Default product card — count available variants #}
    {%- assign available_count = 0 -%}
    {%- for v in product.variants -%}
      {%- if v.available -%}{%- assign available_count = available_count | plus: 1 -%}{%- endif -%}
    {%- endfor -%}
    {%- if available_count == 0 -%}
      <span class="out-of-stock">Out of Stock</span>
    {%- elsif available_count < product.variants.size -%}
      <span class="partial-stock">...Some options sold out...</span>
    {%- else -%}
      <span class="in-stock">...In Stock...</span>
    {%- endif -%}
  {%- endif -%}
</div>
{% comment %} end stock {% endcomment %}
```

## Static Logic Trace — Product ~6829

Product ~6829 (wall light): 1 of 6 colours available (only Copper = 19 units; others = 0).

On the **default product card** (variant = nil):
- `variant != nil` → false → enters `else` branch
- Loop counts: Copper available → `available_count = 1`
- `product.variants.size = 6`
- `available_count == 0` → false
- `available_count < product.variants.size` → `1 < 6` → **true**
- Output: `<span class="partial-stock">Some options sold out</span>` ✓

On a **variant card for Copper** (variant.available = true):
- `variant != nil` → true
- `variant.available` → true
- Output: `<span class="in-stock">In Stock</span>` ✓

On a **variant card for Yellow Brass** (variant.available = false):
- `variant != nil` → true
- `variant.available` → false
- Output: `<span class="out-of-stock">Out of Stock</span>` ✓

## Static Logic Trace — Fully Available Product

`available_count = N`, `product.variants.size = N`:
- `available_count == 0` → false
- `available_count < N` → false
- `else` → `<span class="in-stock">In Stock</span>` ✓

## Static Logic Trace — Completely Sold Out Product

`available_count = 0`:
- `available_count == 0` → true
- Output: `<span class="out-of-stock">Out of Stock</span>` ✓

## Limitations / Notes

- `product.variants` in Liquid returns up to 100 variants. All conduit products are well within this limit.
- The `available_count` variable is local to the stock label block and does not interfere with any other variables in the file.
- Single-variant products (`has_only_default_variant = true`): they have exactly 1 variant. If it is available, `available_count = 1 = product.variants.size` → "In Stock". If not, `available_count = 0` → "Out of Stock". Correct behaviour.
- No hardcoded option names (e.g. "colour") — "Some options sold out" is generic and covers products with size/type/count options as well as colour options.
