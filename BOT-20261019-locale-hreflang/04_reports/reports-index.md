## How to Export from GSC

2. Filter: Page contains `/pl/` (or `/nl/`, `/es/`)
3. Filter: Country = United Kingdom
4. Date range: Last 28 days
5. Export → Download CSV
6. Save to this folder as: `gsc-uk-pl-baseline-YYYY-MM-DD.csv`
