## 2. Investigation Findings

### 2.1 Self-referencing Canonicals

**File:** `layout/theme.liquid` line 53  
**Tag:** `<link rel="canonical" href="{{ canonical_url }}">`  
**Result:** Working correctly on all pages including locale URLs — **NO DEFECT**

### 2.2 Shopify Markets hreflang (auto-generated)

Shopify Markets injects hreflang tags via `{{ content_for_header }}` (theme.liquid line 83).  
**Tags confirmed live on ledsone.co.uk before fix:**

```html
<link rel="alternate" hreflang="x-default" href="https://ledsone.co.uk/products/...">
<link rel="alternate" hreflang="en"         href="https://ledsone.co.uk/products/...">
<link rel="alternate" hreflang="es"         href="https://ledsone.co.uk/es/products/...">
<link rel="alternate" hreflang="pl"         href="https://ledsone.co.uk/pl/products/...">
<link rel="alternate" hreflang="nl"         href="https://ledsone.co.uk/nl/products/...">
<link rel="alternate" hreflang="nl-NL"      href="https://ledsone.nl/products/...">
```

**Missing:** `hreflang="en-GB"` — no UK region signal for the English pages.

### 2.3 Custom hreflang Code (seo-noindex.liquid)

A custom hreflang loop was written on 2025-10-12 but is **entirely commented out** — not active, not causing any issue.

### 2.4 Root Cause

Without `hreflang="en-GB"`, Google has no signal that the English page is specifically for UK users. When a Polish or Dutch-preference user searches from the UK, Google sees:
- `hreflang="pl"` — valid for any Polish speaker globally (including UK)
- `hreflang="en"` — valid for any English speaker globally (no UK specificity)

Result: locale pages surface for UK users with non-English browser language preference.

| EU Market | /pl/ Polish | **Retained — required for international customers** |

## 3. Fix Applied

**Approach:** One theme file change — applies automatically to all 2,612+ pages.  
**File:** `shopify_projects/ledsone-uk-theme/snippets/seo-noindex.liquid`  
**Rendered via:** `theme.liquid` line 148 — active on every page

**Code added (lines 44–53):**

```liquid
{%- comment -%} en-GB hreflang — Markets outputs 'en' (language-only); this adds UK region signal piranav 2026-10-20 {%- endcomment -%}
{%- for locale in shop.published_locales -%}
  {%- if locale.iso_code == 'en' -%}
    {%- if request.locale.iso_code == 'en' -%}
      {%- assign en_canonical = canonical_url -%}
    {%- else -%}
      {%- assign en_canonical = canonical_url | replace: request.locale.root_url, '' -%}
    {%- endif -%}
    <link rel="alternate" hreflang="en-GB" href="{{ en_canonical }}">
    {%- break -%}
  {%- endif -%}
{%- endfor -%}
```

**Logic:**
- On English pages → `en_canonical = canonical_url` (no change needed)
- On locale pages (e.g. /pl/) → strip locale prefix (`/pl`) to produce English URL
- Outputs one `<link rel="alternate" hreflang="en-GB">` tag per page
- Does not duplicate or replace any Markets auto-tags
