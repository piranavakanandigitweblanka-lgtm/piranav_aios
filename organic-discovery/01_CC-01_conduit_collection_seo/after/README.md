# CC-01 — After Screenshots

Save after screenshots here **only after the live page shows the change**.

## What to capture

1. The live conduit collection page — full page screenshot showing the new H1
2. The page source or browser title bar showing the new SEO title
3. The Shopify admin — collection editor showing new SEO title, collection name

## Filename convention

```
CC-01_after_YYYYMMDD_HHMM_live-page-h1.png
CC-01_after_YYYYMMDD_HHMM_browser-title.png
CC-01_after_YYYYMMDD_HHMM_shopify-admin-seo.png
```

## IMPORTANT

Do not save after screenshots until the live page actually shows the change.
Do not create fake or staged screenshots.
