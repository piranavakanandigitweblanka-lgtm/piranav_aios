# CC-01 — Before Screenshots

Save before screenshots here **before making any changes** to the conduit collection page.

## What to capture

1. The live conduit collection page — full page screenshot
2. The Shopify admin — collection editor showing current SEO title, meta description, collection name
3. The page source (or Google Search Console title) showing the current title tag

## Filename convention

```
CC-01_before_YYYYMMDD_HHMM_live-page.png
CC-01_before_YYYYMMDD_HHMM_shopify-admin-seo.png
CC-01_before_YYYYMMDD_HHMM_current-h1.png
```

## Record for each screenshot

- Page URL
- Date and time captured
- What it shows
- What is wrong (e.g. "SEO title is X, should be Y")

## IMPORTANT

Do not overwrite these after changes are made.
These are the permanent "before" record for this task.
