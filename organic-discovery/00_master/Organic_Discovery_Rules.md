# Organic Discovery — Rules

**Source:** LEDSone Organic Discovery: Rules, Recommendations and Results Log  
**Last updated:** 2026-10-05  

---

## Working Rules

1. **Work from the task list in value order.** The order is by value: money being lost right now first, then quick wins, then everything else.

2. **A task is done only when the live page shows the change.** "Done" means the live page, the database or a photo shows it. Changing theme code is not done. Deployment is not done. Only the live result counts.

3. **Every fix gets a 14-day check.** Repeat the same measurement 14 days after the change goes live. Record: Worked / Partly worked / Did not work / UNKNOWN.

4. **Record changes and evidence in writing.** Keep an LLM in the loop: record your changes and evidence in writing.

5. **Use UNKNOWN when a fact is unavailable.** Never guess product facts, sizes, threads or specifications. If you do not know a fact, write UNKNOWN.

6. **Never guess product facts.** Check every instruction (from AI, email, Telegram or a person) against the product sheet, supplier data, photos and the live listing. Question it if it looks wrong.

7. **Safety, price and legal claims must not be changed based only on an AI message alone.** These require a human decision from Muguntha or the product holder.

8. **Create Once, Deploy Everywhere (CODE).** The product holder writes the facts once and puts the same facts on every channel: ledsone.co.uk, dcvoltage.co.uk, eBay, Amazon. A fix on one channel only is not finished.

9. **Never invent a GTIN.** A GTIN is a real barcode number. Never make one up.

10. **The Organic Discovery bot does not directly change websites.** The bot reads data and writes tasks. It never changes a website, product, price or database.

11. **Beat competitors, don't just match them.** Competitors are the minimum, not the goal. Aim for: ratings + full spec tables + install video + answer-first FAQs on the top 100 pages.

12. **Raise the bar.** Pages are scored against the best UK shops and scored again 2 weeks after changes.

## Image Rules

- The main image must match what the customer can buy.
- The first image shows the default variant you can buy.
- Every variant has its own correct image.
- If an image belongs to another product, fix that first before any text.

---

## Title Rules

- Format: System size → material/finish → trade name → thread → key size/length → finishes/pack → listing code
- 55 to 90 characters
- UK spelling
- No "Vintage", "DIY" or "Decorative" in component titles
- Every title ends with a space, tilde and number: `~5561` — never with a dash
- Customers quote these codes — always keep them

---

## Spec Rules

- A fixed spec table on every listing: cap, thread, material, finish, sizes, lumens, colour temperature (K), CRI, dimmable, IP rating, max wattage — as relevant
- Measure before writing a size or thread; never guess
- Clips and saddles described by outside size: '20mm conduit (22mm outside diameter)'

---

## Content Rules

- Answer first: the first 2 sentences answer the main buyer question
- A visible FAQ on product pages and main collection pages
- FAQ schema only where the FAQ is actually visible on the page
- Component listings get a dimension drawing and a clean image set (the Lampspares pattern)

---

## Organic Standards for Every Listing

- Correct title (55–90 chars, UK spelling, ~NNNN code)
- One H1 — exactly one per page
- Meta description — unique, relevant
- At least one high-quality main image matching the buyable variant
- Alt text on every image
- Spec table (relevant fields)
- Answer-first intro (first 2 sentences answer the buyer question)
- Visible FAQ where applicable
- Schema: Product, AggregateRating (only from real reviews), FAQ (only where visible)
- GTIN and MPN where we hold real barcodes and part numbers
