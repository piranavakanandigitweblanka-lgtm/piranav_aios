# CC-02 — Before Screenshots

1. Screenshot of the guide page showing the link in context
2. Screenshot of the destination page showing it is sold out or unavailable

```

CC-02_before_YYYYMMDD_HHMM_destination-<product-slug>.png
```

Do not overwrite after fixes are made.
